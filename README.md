# Задачі на рекурсію

Програма для практичної: розв'язання базових алгоритмічних задач за допомогою чистої рекурсії.

## Що реалізовано

* **Обмеження:** повна заборона використання циклів, списків, масивів та рядкових операцій. Усі задачі розв'язані виключно через рекурсивні виклики та цілочисельну арифметику (`//`, `%`).

1. `task1_print_1_to_n` — виведення всіх чисел від `1` до `n`
2. `task2_print_a_to_b` — виведення чисел від `A` до `B` за зростанням або спаданням
3. `task3_is_power_of_two` — перевірка, чи є число точним степенем двійки (`YES` / `NO`)
4. `task4_sum_digits` — обчислення суми цифр заданого числа
5. `task5_print_digits_reversed` — виведення цифр числа справа наліво
6. `task6_print_digits_direct` — виведення цифр числа зліва направо

## Файл

* `task.py` — реалізація на Python
